# PS5 游戏推荐游玩度排行

把 1120 款 PS5 游戏按「值不值得花时间」排序成一个可筛选的静态榜单。零依赖单文件，打开即用。

**在线版**：https://yimingwang01.github.io/ps5-ranking/

---

## 为什么做这个

商店评分回答不了「我只有 20 小时，该玩哪个」；销量榜回答不了「这个品类我吃不吃」。
这个榜单把「推荐游玩程度」单独拎出来评分，按 S/A/B/C/D/E 分档，每款配一句判断理由 —— 用来做决策，不是做展示。

## 评分怎么来的

**它不是算法算出来的**，这点先说清楚，免得误解：

1. **人工策展表**（`score_ps5.py` 的 `TITLES` + `curate2.py` 的 `C`，合计 1289 条，当前命中 879 条）
   每条形如 `(分数, 品类, 一句话理由)`
2. **类型兜底**：策展表没覆盖的条目，按品类给基准分，并标注「资料有限，口碑待观察」

匹配规则：

- 标题**最长匹配优先**；长度相同时取出现位置更靠前的 —— 避免「副标题命中、主标题落空」
- 另有一张 `FIX` 精确修正表处理子串歧义（例如键 `都市` 会误伤一批无关标题）
- **PS VR 统一降分**：非 VR 品类但支持 VR 的 −0.5；VR 专属/加强的 −0.7（需要持机才划算）

## 分档线

| 档位 | 分数 |
|---|---|
| S | ≥ 9.3 |
| A+ | ≥ 8.8 |
| A | ≥ 8.2 |
| B+ | ≥ 7.5 |
| B | ≥ 7.0 |
| C+ | ≥ 6.5 |
| C | ≥ 6.0 |
| D | ≥ 5.0 |
| E | < 5.0 |

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 成品页面，数据已内联，584 KB 单文件，无外部依赖 |
| `ps5_items.json` | 原始抓取数据（1120 条，含历史累积） |
| `ps5_scored.json` | 评分结果（含 `rank` / `tier` / `genre` / `note`） |
| `ps5-ranking.csv` | 表格版，可直接导入 Excel |
| `build_score.py` | 评分主流程 |
| `score_ps5.py` | 第一遍策展表 |
| `curate2.py` | 第二遍策展表（补齐 419 条「资料有限」） |
| `make_report.py` | 生成 HTML 报告 |

## 重新生成

```bash
python build_score.py     # 评分 + 排序 -> ps5_scored.json
python make_report.py     # 渲染 -> HTML
```

依赖：仅 Python 标准库，无需 pip install。

## 数据来源与声明

游戏清单与基础信息抓取自 [2468c.com/ps5game](https://2468c.com/ps5game) 列表页（每次 40 页 / 1000 条）。
站点只保留最近 40 页，老条目会滚出窗口，因此本项目按 pid 做**历史累积去重**，当前共 1120 款。
**评分、品类归属与一句话点评均为本项目自行判断，与该站无关。**

本站为个人兴趣项目，不提供下载，不做商业用途。游戏名称与商标归各自权利人所有。
